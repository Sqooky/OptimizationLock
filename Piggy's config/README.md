To install The changes to the video.txt you need to edit the file in a way that requires more manual input than replacing the file

Your prexisting video.txt can be found at the following:
- Windows: \steam\userdata\your_steam_id\1422450\local\cfg 
- Linux:  ~/.steam/steam/userdata/your_steam_id/1422450/local/

If you comment out the setting ``UserSettingsPathID       "USRLOCAL"`` video.txt will appear at citadel/cfg/video.txt usable, however if this is commented out it will force you into low violence mode (make drifter and mina purple)

"VendorID"      " " replace with the value found in your preexisting video.txt

"DeviceID"      " " replace with the value found in your preexisting video.txt
