### What The Mod Does
This mod makes the sinner's lights able to be read if your mip bias is set to be below 4
### Credits  
This sinner light fix mod was originally found on piggy's discord server, However the current version was made by HoppCX for The City Never Sleeps update

### Installation
Place this file in your addons folder in Deadlock\game\citadel, just like you would any other mod.
Make sure you have this line in your gameinfo.gi file, inside the searchpaths bracket: ``Game    citadel/addons``
