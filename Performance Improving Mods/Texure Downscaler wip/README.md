### What The Mod Does
This mod downscales the resolution of EVERY texture in the game to 25% of its base resolution. This means that the game should consume a LOT less vram. However this does present some readability issues where the map looks bright white and flat due to this messing with lighting in ways I don't quite understand yet

### Installation
You have to download the mod through the github releases https://github.com/Sqooky/OptimizationLock/releases/tag/mod
Place this file in your addons folder in Deadlock\game\citadel, just like you would any other mod.

Make sure you have this line in your gameinfo.gi file, inside the searchpaths bracket: ``Game    citadel/addons``
